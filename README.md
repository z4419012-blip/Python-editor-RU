Как пользоваться
Версия 1 (Редактор Python V1.exe)
Скачайте файл Редактор Python V1.exe.
Запустите его двойным кликом — установка не требуется.
В чёрном поле редактора напишите код на Python.
Нажмите кнопку Run (жёлтая кнопка с треугольником внизу), чтобы запустить скрипт без предварительного сохранения.
Результат выполнения и ошибки отобразятся в том же окне ниже вашего кода.
Версия 2 (Редактор Python V2.zip)
Скачайте архив Редактор Python V2.zip.
Распакуйте архив в любую удобную папку на компьютере (подойдёт стандартный архиватор Windows или 7‑Zip).
Важно: не удаляйте и не перемещайте файлы из распакованной папки — редактору нужны все сопутствующие файлы для работы. Не открывайте вручную никакие файлы внутри папки, кроме самого редактора.
Запустите файл редактора из этой папки.
В поле редактора напишите код на Python.
Нажмите кнопку Run, чтобы запустить скрипт без предварительного сохранения.
Результат выполнения и ошибки отобразятся в окне вывода.
